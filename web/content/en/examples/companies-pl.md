NIP and REGON never repeat in the table, so each row can stand for a different company. The legal form is drawn from the list in the recipe. Change the list, or add columns of your own with `values`. A correct NIP or REGON can belong to a real company, so keep the file in test systems.

The table has no company names, because this version has no generator for them.
