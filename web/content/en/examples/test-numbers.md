Card numbers come only from the test numbers payment providers publish, so none of them is a real card. Every EAN starts with 952, which GS1 sets aside for examples. The account, routing, book, phone and vehicle numbers can match real ones, so keep the file in test systems.

Use it where an application must take a valid number. [Numbers that should be refused](/examples/bad-check-digits/) is the same table with broken check digits mixed in.
