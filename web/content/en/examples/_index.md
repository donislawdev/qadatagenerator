Each page shows the recipe, what the program printed when it ran it, the first rows of every file it writes and, for a recipe that orders damage, every value it damaged with what your application should do with it. All of that comes from running the recipe with this version of the program, so a page cannot show what the program no longer does.

The same recipes are in the [examples folder](https://github.com/donislawdev/qadatagenerator/tree/main/examples) of the repository. [Recipes](/docs/recipes/) explains every key they use.
