{{- /* A value whose damage wrote the same text in another Unicode form, with each combining mark written as its escape, the way the catalog writes its own example on the page of damage. Drawn on its letter, ż written as z and a dot looks the same as ż, and the page would show a value that did not change. Only the value of that damage is spelt out, never every value with a mark in it: in Devanagari, Hebrew with its vowels or Thai a mark is an ordinary part of a word and has to be drawn. A template cannot work out the code of a character, so the marks are listed, and a mark the list does not have stops the build rather than passing unseen. Takes: the value. Returns: the text to show. */ -}} {{- $value := . | default "" }} {{- $marks := dict "\U00000300" "u0300" "\U00000301" "u0301" "\U00000302" "u0302" "\U00000303" "u0303" "\U00000304" "u0304" "\U00000306" "u0306" "\U00000307" "u0307" "\U00000308" "u0308" "\U0000030A" "u030a" "\U0000030B" "u030b" "\U0000030C" "u030c" "\U00000327" "u0327" "\U00000328" "u0328" }} {{- range $mark, $escape := $marks }}{{ $value = replace $value $mark (printf "\\%s" $escape) }}{{ end }} {{- with findRE `[\x{0300}-\x{036F}\x{1AB0}-\x{1AFF}\x{1DC0}-\x{1DFF}\x{20D0}-\x{20FF}\x{FE20}-\x{FE2F}]` $value 1 }} {{- errorf "the damaged value %q carries a combining mark that layouts/_partials/marks-spelled.html does not list, so the page would draw it on its letter and show no change. Add it to the list" $value }} {{- end }} {{- return $value }}
